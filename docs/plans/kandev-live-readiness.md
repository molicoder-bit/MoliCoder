# Kandev 0.97.0 live readiness, Windows x64

Date: 2026-10-15. The pinned, checksum-verified managed executable ran against an isolated data directory under the MoliCoder application data folder. The service bound only to `127.0.0.1:38429`; `/health` returned `status: ok` and `version: v0.97.0`. A disposable Git repository and Kandev workspace, repository registration, workflow step, and OpenCode profile were used. The profile selected a free model and kept auto approval disabled. No user project was attached.

The ordinary Windows `kandev run --headless` launcher exited before readiness while changing permissions on its supervisor `control.sock`. The same verified executable's `__backend` entry point started successfully with `KANDEV_HOME_DIR`, `KANDEV_BUNDLE_DIR`, host, and port set for the isolated test. This is a Kandev launcher limitation on this host; MoliCoder's managed install does not silently start a service. The executable install and service lifecycle are separate checks.

The first task exposed that an omitted executor ID selects Kandev's local checkout. The pinned REST create request now selects `exec-worktree`. A second task produced a clean, registered Git worktree. Live session data omitted `base_commit_sha`, so MoliCoder uses the base revision it saved before launch and independently verifies repository identity, branch, registered worktree, ancestry, clean status, and changed commit. A MoliCoder-owned run then created and launched a third harmless task, recovered its external ID and messages, validated the exact one-file result, reached `ready_to_apply`, fast-forwarded the disposable fixture, and repeated apply without creating another commit.

The backend was stopped and restarted with the same isolated data. The task remained in review, lookup by external ID returned the same task, and a saved message cursor resumed with zero duplicate messages. The focused REST, run, and worktree tests passed after the live contract fixes. Internal Build remains the default when Kandev is unconfigured. This check did not validate the Windows launcher, another Kandev release, a paid agent, or a real user repository.
